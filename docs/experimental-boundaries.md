# Experimental Boundaries

This repository enforces evidence governance before interpretation.

## Boundary rules

- Raw evidence is immutable after ingestion.
- Corrections occur through append-only supersession.
- Provenance is mandatory.
- Evidence, observation, hypothesis, experiment, result, and interpretation are distinct record classes.
- Missing evidence must not be converted into a negative finding.
- Uncertainty and contradiction must be preserved rather than reconciled away automatically.
- No behavioral or identity claim may be treated as canonical merely because a model generated it.
